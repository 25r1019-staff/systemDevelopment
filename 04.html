社内図書貸出管理システム　詳細設計書（抜粋）
Ver 1.0　対象：S03 貸出登録（機能F03）

見本　※研修用の架空の設計書です。

1. 処理概要

S03「貸出登録」画面で利用者IDと図書IDを受け取り、入力チェックと貸出可否の確認を行ったうえで T_LOANSに貸出レコードを登録する。成功時は完了メッセージを表示してトップ画面（S01）へ遷移する。

2. 確認条件（受け取り前）

種別項目条件
必須利用者ID未入力なら「利用者IDを入力してください」を表示して処理を中断
必須図書ID未入力なら「図書IDを入力してください」を表示して処理を中断
形式利用者ID半角英数字5桁に一致しない場合は「利用者IDは半角英数字5桁で入力してください」を表示
形式図書ID「B」+数字3桁の形式に一致しない場合は「図書IDの形式が不正です」を表示

3. 処理手順（貸出登録ボタン押下時）

処理フロー（フローチャートの文章版）

① 入力チェック（前節の2項）
② M_USERSから利用者IDを検索
　└ 存在しない →「利用者IDが見つかりません」表示・終了
　└ loaning=1（利用停止）→「この利用者は貸出できません」表示・終了
③ M_BOOKSから図書IDを検索
　└ 存在しない →「図書IDが見つかりません」表示・終了
　└ status≠0（貸出不可）→「この図書は現在貸出できません」表示・終了
④ T_LOANSに登録（loan_date＝今日、return_plan＝今日+14日）
⑤ M_BOOKS.statusを「1：貸出中」に更新
⑥ 完了メッセージ（図書ID・書名・利用者名・返却期限）を表示し、S01へ遷移

4. 入出力項目定義

方向項目取得元・出力先
入力利用者IDS03画面の利用者ID入力欄
入力図書IDS03画面の図書ID入力欄
参照書名・著者名M_BOOKS
参照利用者名・部署M_USERS
更新貸出レコードT_LOANS（INSERT）
更新図書の在庫状態M_BOOKS.status → 1（UPDATE）

5. エラー時の動き（例外処理）

事象行うこと
DB接続に失敗した「システムエラーが発生しました。管理者に連絡してください」を表示し、ログ(エラーログ)を記録する
同時に操作され更新が競合した「他の操作と競合しました。もう一度お試しください」を表示し、登録は行わない
登録SQLの実行に失敗した実行中の更新をすべて取り消す（ロールバック）し、エラーメッセージを表示する
注意点：内部設計で「失敗したとき」を書かないと何が起きるか 「うまくいくとき」の手順だけ書いてあっても、製造担当者は「エラーになったらどうするか」を 自分で決めざるを得ず、担当者ごとに動作が変わります。「エラー時・例外時の動き」が 詳細設計書に書かれているかが、プログラムの品質を左右します。

6. 疑似コード（実装イメージ）

// 貸出登録処理（PSEUDO）
function registerLoan(userId, bookId):
  if !validate(userId, bookId) then
    return showError('入力内容を確認してください')
  user = findUser(userId)
  if user == null or user.loaning == '1' then
    return showError('この利用者は貸出できません')
  book = findBook(bookId)
  if book == null or book.status != '0' then
    return showError('この図書は現在貸出できません')
  insertLoan(userId, bookId, today, today + 14days)
  updateBookStatus(bookId, '1')
  moveTo('S01', '貸出登録が完了しました')
